# Statistics for Data Science

🇧🇷 [Leia em Português](README_PT.md)

- Linear Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Bayesian Inference
- Hypothesis Testing
- Model Selection and Regularization
- Bias vs Variance
- Cross Validation
- Feature Selection
- Supervised Learning
- Probability and Statistical Inference

The notebooks were written and organized to reinforce both:
- theoretical understanding
- practical intuition using Python and Jupyter Notebook
